REF013 · Islam 2023
Application of AI/ML in SOC
✗ Sem validação experimental · sem métricas SOC standard · algoritmos ML não testados em produção · zero dimensão humana
→Camada de Telemetria com datasets reais + pipeline CI/CD de modelos + métricas operacionais MTTD/MTTR/FPR
REF015 · Wei et al. 2025
CORTEX: LLM Alert Triage
✗ Dataset limitado (10 cenários) · sensível a prompt injection · 152s/alerta · sem playbooks · sem métricas humanas
→Motor LLM com RAG + dataset diversificado + guard-rails anti-injection + Playbook Engine integrado + HITL
REF016 · IAENG 2024
Ensemble HMM+LSTM+XGBoost
✗ Dataset CIC-IDS-2017 desatualizado · testado só em brute-force · sem integração SIEM/SOAR · sem escalabilidade enterprise
→Pipeline de ingestão multi-fonte com datasets recentes + integração nativa SIEM/SOAR + concept drift adaptation
REF017 · Ban et al. 2021
Combat Alert Fatigue WSVM
✗ Dataset não público · contexto single-enterprise · sem visualização em tempo real · sem generalização multi-contexto
→Dashboard tempo real com tile graphs + modelo transferível multi-org + feature store partilhada
REF025 · Mohsin et al. 2025
CyberAlly HITL Framework
✗ Validação só em cyber range simulado · sem playbook generation · sem módulo de formação · governance nível 4 em aberto
→Framework 5-níveis HITL em ambiente real PME + Playbook Engine + módulo gamificação + governance progressivo
REF026 · Srinivas et al. 2025
AI-Augmented SOC Survey
✗ Heterogeneidade de benchmarks · hallucinations LLM · sem integração legacy · privacidade de dados · sem Capability-Maturity Model
→Benchmark unificado interno + hallucination guard + connectors legacy (Splunk, QRadar) + CMM-SOC integrado
REF027 · Singh et al. 2025
LLMs in SOC Empirical Study
✗ SOC único (eSentire) · GPT-4 específico · sem métricas objectivas de outcome · sem trust calibration longitudinal
→Multi-SOC PME + modelo-agnóstico (MCP) + métricas outcome (MTTR, FPR) + painel trust calibration
REF030 · Karagiannis 2024
NICE-by-Design Cyber Range
✗ Formação isolada do SOC · sem gamificação adaptativa · PR-VAM-001 0% coberta · sem feedback ao SOC
→Módulo gamificação alimentado por incidentes reais + Human Risk Score contínuo + cobertura NICE completa
Arquitetura de 6 Camadas — ONDAS SOC Framework
L1
CAMADA DE INGESTÃO & TELEMETRIA
DATA INGESTION
▼
Recolha normalizada e em tempo real de todas as fontes de dados da organização. Resolve o gap do REF016 (dataset desatualizado) e REF017 (single-enterprise) através de um pipeline multi-fonte agnóstico com concept drift detection integrado e suporte a ambientes PME heterogéneos.
▸ REF016: datasets recentes ▸ REF017: multi-enterprise ▸ REF013: métricas standard ▸ REF026: integração legacy
📡Log Collector
FluentBit · Logstash · syslog-ng
Endpoints, servidores, firewalls, cloud (AWS CloudTrail, Azure AD). Normalização CEF/LEEF.
✓ Corrige gap REF016: fontes diversificadas
🔌Legacy Connectors
Splunk · QRadar · Elastic SIEM
Integração com SIEM existentes via API + parsers customizados para PME sem stack moderna.
✓ Corrige gap REF026: integração legacy
☁️Cloud & SaaS Monitor
Azure AD · AWS · M365 · Salesforce
Monitorização de credenciais, login anómalo, acessos SaaS — cenários reais do CORTEX.
✓ Corrige gap REF015: dataset limitado
📊Feature Store
Redis · Apache Hudi · Delta Lake
Repositório de features partilhado entre modelos ML com versioning e lineage tracking.
✓ Resolve ausência de dados públicos (REF002, REF017)
🔄Drift Detector
River ML · Alibi-Detect
Deteta concept drift em dados de entrada, aciona re-treino automático dos modelos.
✓ Resolve dataset envelhecimento REF016
🔒Privacy Guard
Differential Privacy · Anonymisation
Anonimização automática de dados sensíveis. GDPR compliance para contexto PME europeia.
✓ Resolve gap privacidade REF026
L2
CAMADA DE DETEÇÃO & ANÁLISE MULTIMODELO
DETECTION ENGINE
▼
Motor de deteção em tempo real com ensemble de modelos ML/DL clássicos e modernos. Supera o gap do REF016 (modelo único) e REF013 (sem validação experimental) através de uma abordagem stacking multi-modelo com SMOTE-ENN balanceamento e métricas MTTD/MTTR em produção.
▸ REF016: stacking ensemble validado ▸ REF013: validação experimental real ▸ REF017: WSVM multi-contexto ▸ REF001: validação SOC operacional
🧠Stacking Ensemble
HMM + LSTM + XGBoost (REF016)
Accuracy 99% em deteção intrusão. MTTD ~5.4s, MTTR ~0.19s. Deploy via API REST.
✓ Estende REF016 a múltiplos vetores ataque
⚖️WSVM Alert Classifier
Weighted SVM (REF017)
FPR 0.001%, Recall 99.6% em dados reais. Priorização de alertas críticos com tile graph viz.
✓ Generaliza REF017 a multi-enterprise
🔍Anomaly Detector
Autoencoder + Isolation Forest
Deteção não supervisionada de comportamentos anómalos em cloud e rede (REF005).
✓ Resolve FP elevados REF005 multi-cloud
🦠Malware Classifier
BERT fine-tuned + Transformers
F1: 99.1% classificação malware (REF009). Pipeline contínuo com concept drift adaptation.
✓ Adiciona RE009 concept drift que faltava
📈Benchmark Monitor
MLflow · Prometheus · Grafana
Dashboard métricas unificado: FPR, F1, MTTD, MTTR por modelo. Resolve ausência métricas REF013.
✓ Métricas SOC standard (gap REF013)
🏗️Model CI/CD
Kubeflow · DVC · GitHub Actions
Re-treino automático quando drift detectado. Rollback automático se performance degrada.
✓ Validação contínua em produção real
L3
CAMADA LLM MULTIAGENTE & PLAYBOOK ENGINE
AI AGENTS + PLAYBOOKS
▼
Motor LLM multiagente para triagem inteligente de alertas (estende CORTEX — REF015) com módulo de geração automática de playbooks (gap ausente em toda a literatura). Supera a latência do CORTEX (152s) através de distilação de modelos compactos e resolve a sensibilidade a prompt injection com guard-rails dedicados.
▸ REF015: dataset > 10 cenários ▸ REF015: prompt injection guard ▸ REF015: latência < 152s ▸ REF015: playbooks (gap ausente) ▸ REF026: benchmark unificado ▸ REF026: hallucination control
🎯Orchestrator Agent
LLM (GPT-4o / Claude 3.5) + MCP
Coordena pipeline de 4 agentes. Mapeia alerta → workflow específico. Enforce coerência.
✓ Estende CORTEX com contexto PME
🔎Behavior Analysis Agent
ReAct + Tool Use + SIEM API
Inspeciona metadados, padrões comportamentais, mapeia a MITRE ATT&CK automaticamente.
✓ REF007: cobertura ATT&CK completa
🕵️Evidence Agent
Tool calling · Knowledge Graph
Recolhe evidências de múltiplas ferramentas (AD, logs, endpoint, cloud) em paralelo.
✓ Resolve dataset limitado REF015
⚖️Reasoning Agent
Chain-of-Thought + SHAP
Agrega veredictos, cross-verifica evidências, categoriza (actionable/FP/undetermined) com justificação.
✓ XAI integrada — resolve REF020
📋Playbook Generator
LLM + RAG + MITRE ATT&CK
Gera playbooks passo-a-passo para cada incidente. Personaliza ao contexto PME (setor, stack, dimensão).
★ NOVO — gap ausente em toda a literatura
🔄Playbook Updater
RAG + Threat Feeds + Versioning
Atualiza playbooks existentes quando surgem novas variantes. Knowledge base viva com Git-style versioning.
★ NOVO — playbooks vivos vs. estáticos
🛡️Injection Guard
Prompt Shield + Input Validation
Filtra prompt injection, context shift e adversarial inputs antes de chegarem ao LLM.
✓ Resolve vulnerabilidade REF015
⚡Distilled Model
Model Distillation · Quantization
Modelo compacto (7B-13B) para triagem rápida de alertas de baixo risco. Latência < 20s.
✓ Resolve latência 152s do CORTEX
L4
CAMADA XAI & HUMAN-IN-THE-LOOP (HITL)
ANALYST COLLABORATION
▼
Interface de colaboração entre IA e analistas SOC com explicabilidade completa (XAI) e framework de 5 níveis de autonomia (estende CyberAlly — REF025). Resolve os gaps de fadiga cognitiva (REF018, REF019), desconfiança (REF020), burnout (REF021) e falta de explicabilidade dos playbooks gerados por IA.
▸ REF018: modelos cognitivos integrados ▸ REF019: redução FP percecionados ▸ REF020: XAI em SIEM real ▸ REF021: automação tarefas repetitivas ▸ REF025: ambiente real (não simulado) ▸ REF027: multi-SOC + métricas outcome
🔮XAI Engine
LIME · SHAP · Counterfactuals
Explicações por alerta: "Porquê este veredicto?", feature importance visual, contrafactuais.
✓ Integra XAI em SIEM real (gap REF020)
🎛️HITL Dashboard
React + WebSocket + D3.js
Painel de analista com 5 níveis de autonomia selecionáveis. Feedback loop: aprovação/rejeição treina modelo.
✓ Estende REF025 a contexto real PME
🧘Cognitive Load Monitor
Biometric API · Task Complexity Score
Monitoriza carga cognitiva do analista. Ajusta automaticamente fluxo de alertas em picos.
✓ Modelos cognitivos integrados (REF018)
🔔Smart Alert Prioritizer
WSVM + Contextual Bandits
Priorização adaptativa: aprende com feedback do analista. Reduz alertas Tier-1 até 61% (benchmark REF010).
✓ Resolve 99% FP percecionados REF019
📋Playbook Validator
HITL Review Flow
Analista valida/edita playbooks gerados por LLM. Validações alimentam dataset de fine-tuning.
✓ Confiança em playbooks gerados por IA
📊Trust Calibration Panel
Longitudinal Tracking · Survey API
Monitoriza confiança do analista no sistema ao longo do tempo. Alertas de miscalibration.
✓ Resolve gap trust longitudinal REF027
L5
CAMADA DE GAMIFICAÇÃO & FORMAÇÃO ADAPTATIVA
HUMAN RISK REDUCTION
▼
Módulo de gamificação para colaboradores da organização, alimentado por incidentes reais do SOC. Gap completamente ausente em todos os benchmarks. Transforma o fator humano externo — responsável por 68-82% dos incidentes (Verizon DBIR 2024) — de ponto fraco em linha de defesa ativa.
▸ REF030: formação ligada ao SOC ▸ REF030: gamificação adaptativa ▸ REF030: cobertura NICE completa ▸ REF022: desengajamento precoce ▸ Todos: Human Risk Score (ausente)
🎮Adaptive Mission Engine
Spaced Repetition · IA Adaptativa
Missões diárias de 5 min geradas pelo SOC com base em ameaças reais recentes. Dificuldade ajusta-se ao perfil.
★ NOVO — loop SOC → formação → SOC
🎣Phishing Simulator
GoPhish · LLM Template Gen.
Simulações personalizadas geradas com LLM baseadas em campanhas reais detetadas pelo SOC. Feedback imediato.
★ NOVO — phishing real → treino imediato
🏆Leaderboard Engine
Gamification API · WebSocket
Rankings por equipa/departamento. Pressão social positiva. Badges e certificações por nível NICE.
✓ Engagement > formação tradicional
🚪Cyber Escape Room
WebGL · Narrative Engine
Cenários colaborativos de resposta a incidente baseados em casos reais do SOC. Cobre gap REF030 (narrative).
✓ Resolve gap narrativa REF030
📉Human Risk Score
Bayesian Risk Model · Dashboard
Score de risco por colaborador e departamento, em tempo real. Alimenta analytics do SOC. GDPR-compliant.
★ NOVO — feedback ao SOC (ausente em todos)
📚NICE Coverage Tracker
NIST NICE Framework API
Mapeia competências de cada colaborador ao NICE Framework. Identifica gaps de skill organizacional.
✓ Cobertura NICE completa (REF030 0%→100%)
L6
CAMADA DE ORQUESTRAÇÃO, SOAR & RESPOSTA AUTOMÁTICA
ORCHESTRATION + SOAR
▼
Camada de resposta automática e orquestração que fecha o ciclo: deteção → triagem LLM → playbook → execução → feedback → formação. Integra com ferramentas SOAR existentes e adiciona o RL-driven playbook optimization que faltava no REF006.
▸ REF006: RL playbooks em produção real ▸ REF003: pipeline CTI → SOAR automático ▸ REF008: SIGMA rules geradas por LLM
⚙️SOAR Integrator
Shuffle · TheHive · Cortex
Execução automática de playbooks aprovados. Integração com ticketing, firewall, AD, email.
✓ Integração SOAR real (gap REF013)
🤖RL Playbook Optimizer
Reinforcement Learning (PPO)
Otimiza sequência de ações nos playbooks baseado em resultados reais. Supera simulação REF006.
✓ RL em produção real (gap REF006)
🌐CTI Pipeline
MISP · STIX/TAXII · NLP (BERT)
Extração automática IoCs de relatórios CTI → SOAR. F1 91.3% (REF003). Multilíngue.
✓ Pipeline CTI→SOAR automático (REF003)
📜SIGMA Rule Generator
LLM + Rule Validation
Gera regras SIGMA para novos padrões de ataque detetados. 83% precisão (REF008) + validação automática.
✓ Avaliação automática (gap REF008)
🔁Feedback Loop
Event Streaming · Kafka
Resultados de incidentes fechados alimentam modelos ML, LLMs e módulo de gamificação. Ciclo fechado.
✓ Loop SOC→Formação→SOC (único)
📊CMM-SOC Dashboard
Capability Maturity Model
Mede maturidade do SOC nos 8 domínios (REF026) + Human Risk Score. Roadmap de evolução automático.
✓ CMM-SOC (gap REF026)
